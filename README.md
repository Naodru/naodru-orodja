## 🛠️ Orodja

| Datoteka | Namen |
|----------|-------|
| `index.html` | Domača stran z vsemi povezavami |
| `generator-objav.html` | AI Generator FB/IG objav |
| `seedance-generator.html` | AI Video prompti (Seedance 2.0) |

## 🔑 API ključ

Za AI funkcije potrebuješ Claude API ključ:
1. Pojdi na [console.anthropic.com](https://console.anthropic.com)
2. Registriraj se in dodaj kredit ($5-10 za začetek)
3. Ustvari API ključ (začne se z `sk-ant-...`)
4. Vnesi ga v rumeno polje v vsakem orodju
